# Template — Story

```
Story — <título curto, orientado a resultado>

História
Uma frase no formato clássico. Se não conseguir escrever assim, a story ainda não está clara.
Como <persona/usuário>, quero <ação> para <benefício / porquê>.

Critérios de aceite
Formato dado/quando/então. É isso que o review e o QA checam.
* Dado <situação>, quando <ação>, então <resultado>
* Dado <...>, quando <...>, então <...>
* <estado de erro / vazio, se aplicável>

Fora de escopo
<O que NÃO faz parte desta story — evita ela crescer no meio do caminho.>

Dependências / notas
<Bloqueios, feature flag, precisa de outra story antes, ponto de atenção técnico.>

Definition of Done (padrão do time — lembrete)
* Critérios de aceite passando
* Code review aprovado <por quem>
* Testes cobrindo o caminho principal
* Deployado no ambiente alvo
```
