# Template — Request (porta de entrada)

> Request é o pedido cru vindo de fora do time. Ele **não descreve solução** — captura o
> que foi pedido e termina numa **decisão de triagem**. Mantenha leve.

```
Request — <o que está sendo pedido, em uma frase>
Solicitante: <quem pediu — pessoa / área / cliente>

1. O pedido (como veio)
<o que foi pedido, nas palavras do solicitante — sem traduzir pra solução ainda>

2. Dor / resultado esperado
<o problema que o solicitante quer resolver e o resultado que ele espera — não a solução>

3. Urgência / contexto
<tem prazo? do que depende? impacto se não fizer? por qual canal chegou?>

4. Triagem (decisão do time)
* Vira: <Epic / Feature / Story / Bug / Chore / Spike / recusado>
* Card(s) gerado(s): <link>
* Por quê: <justificativa da classificação / ajuste combinado com o solicitante>
```
