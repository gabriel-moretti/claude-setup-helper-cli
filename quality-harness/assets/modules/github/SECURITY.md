# 🔒️ Política de segurança

## Como reportar uma vulnerabilidade

**Não abra issue pública.** Use o canal privado do GitHub:
[Report a vulnerability](https://github.com/OWNER/REPO/security/advisories/new) (Security Advisories).

Inclua: descrição, impacto, passos para reproduzir e versão afetada. Nunca envie dados reais de cartão (PAN, CVV), credenciais ou dados pessoais — use dados sintéticos.

## O que esperar

- Confirmação de recebimento em até 2 dias úteis.
- Avaliação inicial e severidade em até 5 dias úteis.
- Correção via `hotfix/…` e aviso publicado no Security Advisory quando a versão corrigida (`vX.Y.Z`) sair.

## Versões suportadas

Somente a última versão `vX.Y.Z` publicada em produção recebe correções de segurança.
